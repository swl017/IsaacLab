# Asset Module

## Purpose
Robot and sensor USD asset files for the iris_ma6 multi-agent environment.
Contains the articulated quadcopter model with gimbal and camera sensor
definitions in Universal Scene Description (USD) format.

## Inputs
None (static asset files loaded by Isaac Sim).

## Outputs
- USD stage primitives: articulated drone body, gimbal joints, camera sensors

## Dependencies
None (standalone asset directory).

## Key Files
- `iris_gimbal3.usda` - USD ASCII file defining the Iris quadcopter with
  3-axis gimbal and camera sensor attachment points

## Spec
None (asset-only module).
